# Revisiones de ChatGPT

## Cómo se añaden

1. ChatGPT entrega cada revisión al director.
2. El director se la pasa a Claude.
3. Claude la copia **literalmente**, sin cambiar su contenido ni añadir conclusiones.

## Formato de cada entrada

```
## REV-NNN · <título que dé ChatGPT, o «sin título»>
Transcrita por Claude el AAAA-MM-DD a partir del texto entregado por el director.
Revisa: <rama / commit / INF-NNN, si la revisión lo indica>

<texto literal de la revisión>
```

La respuesta de Claude a cada revisión va en [INFORMES_CLAUDE.md](INFORMES_CLAUDE.md), como `INF-NNN · Respuesta a REV-NNN`, nunca en este archivo.
